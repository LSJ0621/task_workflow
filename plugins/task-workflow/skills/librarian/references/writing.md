# 글쓰기 규칙

지식 베이스에 문서를 쓸 때 지킨다. 기록, 메모, 카드, 상황판 모두 같다. 새로 쓸 때도, 고칠 때도 같다.
지식 베이스에 쓰는 다른 스킬도 이 파일을 본다. 사서가 플러그인 설치 없이 이 폴더만 읽는 경우가 있어서 사서 폴더에 둔다.

- 쉬운 일상 단어를 쓴다. 전문 용어는 꼭 필요할 때만 쓴다.
- 지식 베이스 안에서만 통하는 말이나 비유 단어(층, 경계, 흐름 같은 것)를 새로 만들지 않는다. 꼭 써야 하면 처음 나올 때 괄호로 풀이를 붙인다.
- 한 문장에는 한 가지 내용만 담는다. 두 가지가 들어가면 문장을 나눈다.
- 결론을 먼저 쓰고 이유를 뒤에 쓴다.
