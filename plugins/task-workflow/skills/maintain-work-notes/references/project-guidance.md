# 프로젝트 AGENTS.md에 재개 지침 연결

프로젝트 적용·재개 지침 설정을 요청받았을 때만 사용한다. 일반 기록·조회·분석·검증 요청이나 플러그인 설치·업데이트는 AGENTS.md 수정 요청이 아니다.

## 적용

1. 대상 프로젝트와 적용 중인 상위·하위 AGENTS 지침, 실제 기록 진입점을 확인한다. 기존 기록 관례를 우선하고, 기록이 없으면 `docs/work-notes/INDEX.md`를 후보로 안내하되 없는 문서를 있다고 쓰거나 이 설정만을 위해 INDEX·STATUS를 생성하지 않는다.
2. 기존 AGENTS.md의 지침을 보존하고 같은 역할의 문장이 있으면 중복 없이 보완한다. 기존 지침과의 충돌을 임의로 덮어쓰지 않는다. 사용자 전역 AGENTS나 다른 프로젝트는 수정하지 않는다.
3. 아래처럼 스킬 재로드 시점과 실제 문서 진입점만 짧게 남긴다. 문서 작성·정리·해시·Git 보존 규칙 전체를 복사하지 않는다. 설치 경로의 버전 번호를 하드코딩하지 않는다.

```markdown
## 작업 맥락 재개
- 새 세션·재개·compact 후 작업을 이어가기 전에 설치된 task-workflow:maintain-work-notes의 SKILL.md와 필요한 STATUS 운영 참조를 다시 읽어 적용한다. 재개 자체를 구현·재설계 허가로 해석하지 않는다.
- 프로젝트 기록은 docs/work-notes/INDEX.md에서 찾고 현재 작업에 필요한 문서만 읽는다.
```

위 진입점은 예시다. 실제 기록 위치로 바꾸고, 기록이 없으면 기존 `docs/` 관례에서 INDEX가 있는지 확인하도록 적는다. 스킬을 사용할 수 없는 환경에서는 그 사실을 알리고 확인 가능한 INDEX·STATUS·관련 문서로 상황을 파악한다.

## 적용 확인과 한계

- 추가·변경한 짧은 지침과 연결 위치를 보고한다. 내용 변경을 현재 실행 중인 모든 세션이 즉시 반영한다고 가정하지 않는다. 적용 후 새 Codex 실행에서 해당 지침이 로드되는지 확인한다.
- AGENTS는 재로드를 지시하는 진입점이며 실행 훅이나 동기화 장치가 아니다. 실제 compact 뒤 스킬·참조를 다시 읽고 STATUS 변경을 감지하는지는 별도 행동 검증 대상으로 둔다. 그 검증을 수행하지 않았으면 자동 복구가 보장된다고 보고하지 않는다.
- 이 스킬을 설정하는 현재 세션이 다른 프로젝트에 지침을 일괄 설치하거나 전역 설정을 변경하지 않는다.
