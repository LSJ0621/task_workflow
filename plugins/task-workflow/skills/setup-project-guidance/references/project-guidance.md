# 프로젝트 지침 작성·연결 기준

## 선별할 내용

기존 상위·하위 지침(AGENTS.md, CLAUDE.md, 규칙 파일)과 프로젝트 관례를 확인하고 같은 역할의 내용은 중복 없이 보완한다.
현재 작업 한 번의 요청·진행 상황이 아니라 프로젝트에서 계속 적용할 필요가 있는 지침을 선별한다.

- 응답 방식: 사용자가 명시한 말투·길이·보고 선호.
- 작업 맥락: 기록 스킬을 사용하는 연결 문구와 실제로 존재하는 문서의 위치·역할.
- 작업 범위: 사용자와 합의한 범위·변경 제한.
- 구현 제약: 기존 자료·설정에서 확인한 프로젝트 고유 원칙.
- 커밋·푸시: 사용자와 프로젝트가 정한 허용 범위·시점.

위 항목은 후보이며 모두 채워야 하는 고정 양식이 아니다. 확인되지 않은 응답 선호·커밋 권한·기술 선택·업무 정책을 기본값처럼 만들어 넣지 않는다.
자료에서 확인되는 사실과 사용자 지시를 근거로 쓰고, 추가 제안은 제안임을 표시해 검수받는다. 서로 다른 근거가 충돌하면 임의로 우선순위를 만들어 덮어쓰지 않는다.
이미 주제 문서에서 관리하는 업무 정책·상세 기준은 문서의 역할과 링크로 안내한다. 루트 지침에 직접 남길 내용은 작업 전반에 적용할 핵심 제약으로 한정한다. 한 폴더나 한 종류의 파일에만 걸리는 지침은 [지침 장치 표](instruction-surfaces.md)에서 고른 장치에 두고, 같은 내용을 두 곳에서 관리하지 않는다.

## 기록 스킬 연결

task-workflow를 사용하는 프로젝트에는 아래처럼 스킬 이름으로 기록 기능을 연결한다.

```markdown
## 작업 맥락

- 작업을 시작하거나 이어갈 때는 task-workflow:maintain-work-notes로 프로젝트 기록의 현재 맥락을 확인한다.
- 스킬을 사용할 수 없으면 그 사실을 알리고, 확인 가능한 프로젝트 문서로 맥락을 파악한다.
```

프로젝트의 실제 INDEX가 확인되면 그 상대경로를 문서 진입점으로 추가한다. README 등은 실제로 존재하고 필요한 역할을 확인했을 때만 연결한다.
기록이 없는 프로젝트에 가상의 INDEX·STATUS·기술스택 문서 링크를 넣거나 이 설정만을 위해 해당 파일을 생성하지 않는다. 특정 프로젝트의 경로·기술·업무 규칙을 모든 프로젝트의 기본 지침으로 복제하지 않는다.

기록 스킬 내부 파일인 SKILL.md·reading.md를 직접 읽으라는 문구, 해시 명령·비교 조건·매 요청 확인 절차, 문서 역할·정리·검증·Git 보존 절차 전체를 지침 파일에 복사하지 않는다. 이런 상세 규칙은 해당 스킬이 소유한다.
캐시 설치 경로·버전 번호를 하드코딩하거나 새 세션·compact 후 설정 스킬 자체를 반복 실행하도록 만들지 않는다.

## 기존 지침과 연결 파일

사용자의 기존 변경·지침과 원문 보존 의사를 유지한다. 같은 의미의 문장이 있으면 중복 추가하지 않고 필요한 부분만 보완한다.
진행 일지·기획 상세가 지침 파일에 섞여 있으면 기록 스킬로 분리할 필요성을 제안한다. 설정만 요청받았다는 이유로 보존되지 않은 원문을 지우거나 다른 기록 파일로 임의 이동하지 않는다.

루트 지침 파일은 이미 있는 것을 따른다. 새로 만들 때는 AGENTS.md로 한다.
Claude Code를 쓰는 프로젝트에서 AGENTS.md가 읽히게 하는 방법은 [지침 장치 표](instruction-surfaces.md)의 "두 도구를 같이 쓰는 저장소" 항목을 따른다.

- CLAUDE.md나 CLAUDE.local.md가 이미 있으면 초안에 CLAUDE.md의 `@AGENTS.md` 연결을 함께 제안한다. 없을 때만 추가하고, 기존 내용·다른 연결 방식은 보존한다.
- 둘 다 없으면 연결만을 위한 CLAUDE.md를 만들지 않는다. Claude Code에만 걸리는 내용이 있거나 그 세션이 AGENTS.md를 직접 읽지 못할 때만 제안한다.
- 하위 폴더 지침을 제안할 때는 두 도구가 읽는 때가 다르다는 것을 초안에 적는다.

사용자 전역 AGENTS·CLAUDE 설정이나 다른 프로젝트에 지침을 일괄 적용하지 않는다.

## 확인할 한계

지침 파일은 읽히기만 하고 강제되지 않는다. 실행 훅이나 동기화 장치가 아니다. 적용 후 새 세션의 지침 로드, 스킬 선택, 실제 compact 후 동작은 수행한 경우에만 검증됐다고 보고한다.
Claude Code에서 하위 폴더 지침과 경로 조건 규칙은 세션을 시작할 때 읽히지 않는다. 그 폴더나 파일을 다루게 한 뒤에 읽혔는지 본다.
장치마다 읽히는 때와 공식 문서 주소는 [지침 장치 표](instruction-surfaces.md)에 있다. 표의 확인한 날짜가 오래됐거나 도구 버전이 바뀌었으면 공식 문서를 다시 본다.
