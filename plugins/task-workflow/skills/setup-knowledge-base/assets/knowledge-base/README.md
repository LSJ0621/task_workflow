# {{REPO_NAME}}

{{OWNER}}의 개인 지식 베이스. 에이전트가 모르는 맥락을 담는 곳이다. 개발뿐 아니라 생활·취향·상황까지 들어간다.
에이전트가 나 대신 판단할 때 읽는다. 결정과 그 이유, 문제가 있었던 일과 그때 오간 말, 나와 내 상황에 대한 사실을 담는다.

- `raw/`에는 일어난 일(메모, 사례, 결정, 맥락)이 쌓인다. 낮에는 작업 세션이 메모 한 줄만 남기고, 새벽에 그 메모가 가리키는 세션 기록에서 원본 기록을 뽑는다. 확인을 통과한 기록만 확정된다.
- `wiki/`에는 확정된 기록에서 만든 요약이 있다. 맥락 요약(`wiki/context.md`), 프로젝트 카드, 규칙별 사례표, 프로젝트마다 어디까지 왔는지 적는 상황판이다.
- 무엇이 어디 있는지는 `INDEX.md`에 있다.

기록을 어떻게 쓰는지 같은 규칙과 일하는 규칙은 이 저장소가 아니라 `task-workflow` 플러그인의 스킬에 있다. 쌓인 사례를 근거로 규칙을 고치는 일은 자가 발전(`analyze-context`)이 하고, 무엇이 바뀌었는지는 주 1회 점검 보고서(`raw/reviews/`)로 본다.
