# {{REPO_NAME}}

{{OWNER}}의 개인 지식 베이스. 개발뿐 아니라 생활·취향·상황까지, 에이전트가 모르는 나에 대한 맥락을 쌓는 곳이다.
에이전트가 나 대신 판단할 때 읽는다. 결정과 그 이유, 에이전트의 실수와 내가 고친 말, 나와 내 상황에 대한 맥락을 담는다.

- `raw/`에는 일어난 일(메모, 사례, 결정, 맥락)이 쌓인다.
- `wiki/`에는 그 기록에서 만든 규칙별 사례표와 프로젝트 카드, 프로젝트마다 어디까지 왔는지 적는 상황판이 있다.
- 무엇이 어디 있는지는 `INDEX.md`에 있다.

기록을 어떻게 쓰는지 같은 규칙과 일하는 규칙은 이 저장소가 아니라 `task-workflow` 플러그인의 스킬에 있다. 쌓인 기록으로 규칙을 정하거나 고칠 때는 맥락 분석(`analyze-context`)을 쓴다.
