# 이 저장소는 지식 베이스다

에이전트가 모르는 맥락을 담는 저장소다. 사용자에 대한 사실(일, 생활, 취향, 상황), 정한 것과 이유, 문제가 있었던 일이 들어간다. 규칙은 두지 않는다. 무엇이 어디 있는지는 `INDEX.md`에 있다.

여기서 연 세션은 어느 프로젝트에도 속하지 않는 대화(생활, 계획, 지식 베이스 관리)를 하는 곳이다. 프로젝트 작업은 그 프로젝트 폴더에서 연 세션이 한다.
메모를 남기고 상황판을 고칠 때는 `task-workflow:leave-memo` 스킬을 따른다. 원본 기록은 낮에 손으로 만들지 않는다. 새벽에 `task-workflow:write-records` 스킬이 세션 기록에서 뽑아 만든다.
확정된 기록을 요약과 카드에 올리는 일은 `task-workflow:librarian` 스킬을 따른다.
