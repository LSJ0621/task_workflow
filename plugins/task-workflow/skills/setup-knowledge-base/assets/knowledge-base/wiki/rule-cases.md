# 규칙별 사례표

사례(`C-`)마다 관련 규칙과, 사례가 그 규칙과 어떤 관계인지 적는다. 사서가 정리 때 줄을 더한다.
규칙을 정하는 건 맥락 분석(`task-workflow:analyze-context`)이다. 사례 원본은 `raw/cases/`에 있다.
규칙과 관계는 넷 중 하나다. `규칙을 뒷받침`(내가 고친 방향이 규칙과 같다), `규칙과 반대`(규칙대로 했는데 고쳐졌다), `규칙 없음`(맞는 규칙이 없다), `기각`(사례가 기각됐다).
