# 상황판

프로젝트마다 지금 어디까지 왔는지 적는다. 프로젝트 하나에 `## <프로젝트 이름>` 묶음 하나.
그 프로젝트에서 일한 세션이 작업 단위가 끝날 때 자기 묶음만 고친다. "지침 후보"는 자가 발전이 그 프로젝트에만 걸리는 규칙 후보를 적어 두는 줄이고, 그 프로젝트 세션이 프로젝트 지침으로 옮긴다(`task-workflow:leave-memo`). 묶음 형식은 이렇다.

```markdown
## <프로젝트 이름>
- 어디까지:
- 다음 할 일:
- 막힌 것: 없음
- 지침 후보: 없음
- 고친 날짜: YYYY-MM-DD
```

아직 프로젝트가 없다.
