# 이 저장소는 지식 베이스다

여기서 열린 세션은 **비서**로 동작한다. `task-workflow-assistant:run-assistant` 스킬을 따른다.
시작할 때 `wiki/board.md`와 오늘의 `raw/journal/`을 읽는다. 기준 문서는 팀장이 읽으므로 비서는 읽지 않는다.

- 무엇을 어디서 찾는지는 `INDEX.md`. 기록 규칙은 `wiki/conventions.md`. 불변 조건은 `README.md`.
- 메모·기록·카드는 main에 바로 커밋하고 push한다. 기준 문서 수정과 파일 이동·병합은 브랜치와 PR로 한다.
- 비밀값과 고객 인프라 식별자는 어디에도 적지 않는다.
- 문서를 쓸 때는 `wiki/conventions.md` 글쓰기 절을 따른다.
