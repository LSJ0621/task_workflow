# 회귀 질문

이 저장소가 답해야 하는 질문들. 리팩토링 전후로 같은 답이 나와야 한다.
중요한 걸 기록할 때마다 질문을 하나 보탠다. "답 위치"는 현재 기준이고, 리팩토링 후 바뀔 수 있다. 답 내용이 같으면 통과다.

grep과 색인으로 못 찾는 질문이 3개를 넘으면 검색 서버를 고려한다.

| # | 질문 | 답 위치 | grep으로 찾히나 |
| :- | :- | :- | :- |
| 1 | 이 지식 베이스는 어떤 구조로 시작했고 왜인가? | D-{{DATE}}-01 | 예 |
| 2 | 원본 파일에서 고쳐도 되는 필드는? | README.md 불변 조건 3, wiki/conventions.md | 예 |
